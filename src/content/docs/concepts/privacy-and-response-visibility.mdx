## Who sees what

| Role | Respondent identity | Response detail |
| --- | --- | --- |
| **Student** | Sees only their own | Own submission, read-only after submitting |
| **Faculty Member** | **No** | **Anonymized** submitted responses only |
| **Program Head** | **Yes** | Identified submitted responses, within their program |
| **General Education Coordinator** | No | Aggregate General Education evidence only |
| **College Dean** | **No** | **Anonymized** submitted responses only |
| **Secretary** | No | No response content |
| **Alumni / Industry Partner** | Sees only their own | Own submission, read-only |

:::caution
The identified/anonymized split is enforced on the server and is not a display
setting. A Faculty member or a Dean cannot reach identified detail by any route.
:::

## Drafts are never reviewable

In-progress drafts are not fetched by any review surface. Only a **Submitted**
response can be opened. Nobody — no administrator — can read your draft.

## One response, permanently

Each evaluation assignment accepts exactly one submitted response. That response
cannot be edited, withdrawn, or deleted by anyone, including the person who
submitted it.

## Qualitative feedback is not automatically reusable

:::caution
Removing a name from a comment does not make the comment publishable. Raw
qualitative comments need a separate privacy decision before they are quoted,
circulated, or reproduced — including internally.

Do not assume a comment is safe to quote merely because account identifiers have
been removed.
:::

## Minimum-response suppression

:::caution
The behaviour for very small response groups is still an **open product
decision**. Do not build a reporting practice that assumes a specific suppression
rule; check the current behaviour before publishing any small-group figure.
:::

## Account changes do not erase evidence

Deactivating an account, or transitioning a Student to
[Alumni](/secretary/student-to-alumni/), stops future access. It never removes
responses already submitted. Submitted evidence stays attributable to the term in
which it was collected.
