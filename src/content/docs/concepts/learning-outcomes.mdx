System CLOIE stores three kinds of learning outcome at three levels of breadth.

## Institutional Learning Outcome

An **ILO** is what the college expects across every program. There are only a
handful.

Owner: the **General Education Coordinator**, college-wide. Everyone else reads
them; nobody else changes them.

## Graduate Outcome

A **GO** is what graduates of one program should be able to do.

Owner: that program's **Program Head**.

:::caution
**GO** is the current term. Older material — this Help Center's own search index
included — may call it PLO or "program learning outcome". Same thing; the
application says GO.
:::

## Course Intended Learning Outcome

A **CILO** is what one Course is meant to produce. It is the narrowest of the
three.

Owner: the **Faculty** assigned to that Course. CILOs belong to the Course, not
to the person.

## Who maintains each outcome

| Outcome | Scope | Owner |
| --- | --- | --- |
| ILO | College | General Education Coordinator |
| GO | Program | Program Head |
| CILO | Course | Assigned Faculty |
| **Alignment** between them | CILO → GO or ILO | **Faculty** |

## Which one does this Course support?

| The Course is | Its CILOs map to |
| --- | --- |
| General Education | ILOs |
| Program-specific | the program's GOs |

That is decided by the Course's **scope**, not by whoever is authoring.
