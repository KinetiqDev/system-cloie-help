The **Dashboard** summarizes the program you currently have selected.

## Current program

The dashboard always reports one program. If you manage several, confirm which
one is active before you read any number — see
[Select the program you are working with](/program-head/select-program/).

## What the dashboard summarizes

| Figure | What it counts |
| --- | --- |
| Courses in the program | Program-specific Courses available to assign and evaluate |
| Course assignments | Assignments in the active academic period |
| Ready contexts | Assignments whose CILOs are all aligned |
| Missing CILO / incomplete mapping | Alignment work still owed by Faculty |
| Deployments | Published and scheduled evaluations, by status |
| Responses received | Submitted responses, with completion against assigned |

A **ready** context is one that could have an evaluation published. It is not a
statement about whether outcomes were met.

## Where to go next

- Alignment gaps → [CILO alignment review](/program-head/outcome-alignment/)
- Nothing assigned → [Program Course assignments](/program-head/course-assignments/)
- Ready to reach Alumni or Industry Partners → [Publish a Program-wide evaluation](/program-head/publish-program-evaluation/)
- Results to read → [Review responses](/program-head/responses/) or [Program analytics](/program-head/analytics/)
