**Programs** is the top of the academic structure. A Course is either a
Program-specific Course belonging to a program, or a General Education Course
that belongs to no single program.

## Create a program

1. Select **Create Program**.
2. Enter the program code and name.
3. Add its majors.
4. Confirm.

A program code is permanent — it is used on Courses, assignments, and reports.
Pick it carefully.

## Add or update majors

Add a major from the program's own row. A major is a named specialization inside
a program, and Students are placed at program-and-major level.

## Activate or deactivate a program

Deactivation keeps the program and all of its history but stops it appearing as
a choice for new records. Use it for a program that is closing intake.

## Delete a program

Deletion is deliberately strict. A program can only be deleted when nothing
depends on it — no Courses, no assignments, no Students, no outcomes. If
anything does, the action is **Deletion blocked** and lists what is holding it.

## Why deactivation is usually safer

Deactivating preserves the records that the rest of the institution cites. A
deleted program leaves holes in historical evaluation evidence. Reach for
deactivation unless you are correcting a record that was created in error.

See [Programs, majors, and Courses](/concepts/programs-majors-courses/) for how
programs relate to Courses and assignments.
