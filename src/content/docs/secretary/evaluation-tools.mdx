The **Evaluation Tools** page holds the college's institutional baselines. A
baseline is the starting point every other role derives from — it is a tool you
author once so Program Heads and Faculty do not each rebuild it.

## What an institutional baseline is

A versioned question set with no Course of its own. It becomes usable as a real
evaluation only after someone publishes it against a Course assignment or a
program-wide deployment.

## Course-bound and Program-wide tools

| Kind | Bound to | Published by |
| --- | --- | --- |
| Course-bound | One Course assignment | Faculty on their own assignment, or the Dean/Secretary on behalf |
| Program-wide | A whole program and a chosen respondent group | Program Head, within their authorized programs |

The Secretary creates the baseline; publishing is a separate act by the role
that owns the target.

## Create a baseline

1. Select **New Instrument**.
2. Name it something people will recognize in a dropdown.
3. Set its **Template Type** — **Course-bound** or **Program-wide**.
4. Add questions, using the question types the response form supports:
   - **Likert** — a rating statement on a scale.
   - **Guided Open-Ended** — a written prompt with guidance.
   - **Predefined Responses** — a fixed choice list.
5. For Likert questions, define **Scale Descriptors** so the same scale means the same thing everywhere.
6. Save.

## Add questions

Questions are grouped into sections. A section with no questions is not shown to
respondents. Keep the section count small — respondents answer on a phone.

## Make a Course-bound baseline available to Faculty

A baseline is not published just by existing. Faculty can only start from it once
it is published for their Course-assignment context. Until then it appears as a
template source for the roles that own it, not as something they can publish.

## Versions and published evaluations

Saving a tool records a **version**. A published evaluation is frozen against the
version it was published from: later edits create a new version and never change
an evaluation that is already running or closed.

## Activate, deactivate, duplicate, or remove a baseline

- **Archive** keeps history and stops new use.
- **Save as Program Copy** duplicates the tool so a Program Head can adapt it without touching the institutional original.
- **Delete Template** removes an unused tool. A tool that has ever been published from cannot be deleted, because responses reference it.
