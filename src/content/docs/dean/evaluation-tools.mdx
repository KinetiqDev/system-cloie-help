Dean evaluation-tool work lives under **Academic Structure → Evaluation Tools**.
It mirrors the Secretary's baseline tools and adds one capability: **publishing
on a Faculty member's behalf**.

## What you can do here

- Review and maintain the college's institutional baselines.
- Create a new instrument and its question sections.
- Save versions; a published evaluation always points at the version it was
  published from.
- **Publish a Course-bound evaluation for a Faculty member's assignment.**

## When to publish on behalf

Use on-behalf publishing when an evaluation must run and the assigned Faculty
member cannot publish it themselves — a Faculty member on leave, or a term
closing before the evaluation is out.

The deployment records that it was made on their behalf, so the evidence trail
is not misattributed.

:::caution
Publishing is irreversible in practice. Once an evaluation is published:

- the instrument version is frozen for that evaluation;
- ordinary roster writes are locked;
- one respondent assignment is created per active roster member, minus recorded exclusions.

Preview the respondents before you publish.
:::
