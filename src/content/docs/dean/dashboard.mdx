The **Dashboard** is your starting point for the day. It summarizes
college-wide learning-outcome alignment for one academic period.

## What the dashboard summarizes

| Figure | Meaning |
| --- | --- |
| Active contexts | Course-assignment contexts with alignment work in progress |
| Ready contexts | Contexts where every active CILO satisfies the alignment rule |
| Missing CILO | Contexts with no active CILOs at all |
| Incomplete mapping | Contexts that have CILOs but not all of them aligned |

Each figure is a count of **contexts**, not of Students or of outcomes. A
context is one Course assignment in one academic period.

## Academic-period context

The dashboard defaults to the **active academic period**. It is a read model —
changing the period changes the numbers, it does not change any record.

If the numbers look wrong, confirm the active period before investigating
anything else. See [Academic periods in System CLOIE](/concepts/academic-periods/).

## What the figures mean

- **Ready** does not mean outcomes were *met*. It means the alignment structure is
  complete enough to publish an evaluation.
- **Missing CILO** usually means Faculty have not authored CILOs yet — a
  teaching-preparation gap, not a data error.
- **Incomplete mapping** is a mapping gap: some CILOs are aligned and some are not.

## Where to investigate next

- Readiness detail and mapping-gap rows → [Review learning-outcome readiness](/dean/learning-outcomes/)
- Programs with the most gaps → [Academic structure](/dean/academic-structure/)
- A context with no CILOs → ask the assigned Faculty member, or the Program Head
- A context with no assignment → [Course assignments](/dean/course-assignments/)
