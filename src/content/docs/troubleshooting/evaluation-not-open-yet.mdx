**Problem.** Your teacher published the evaluation, but nothing appears for you
yet.

## Check this first

The evaluation's **Available from** date on the publishing screen. An evaluation
can be published days or weeks before its window opens.

## Why this can happen

Deployment status is **derived from the window**, not set by hand:

| Status | Meaning |
| --- | --- |
| **Scheduled** | Published; the activation time has not arrived |
| **Active** | Inside the window |
| **Closed** | Past the deadline |

Publishing is not the same as opening. This is deliberate — it gives respondents
notice.

## What you can do

- Wait until the activation time, then reload your Evaluations page.
- Note the **Deadline** so you do not miss the window.
- If you need the window brought forward, ask — only the publishing role can
  change it.

## When the problem continues

If the activation time has passed and the evaluation still does not appear, the
problem is eligibility, not timing. Continue with
[I cannot see an evaluation](/troubleshooting/evaluation-not-visible/).
