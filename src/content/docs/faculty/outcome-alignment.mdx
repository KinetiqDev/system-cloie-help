Alignment is what makes a response mean something later. It is the step that
connects what a Course teaches to what the program promises.

## Which outcome should a CILO map to?

It depends on the Course's scope, not on your preference:

| Your Course is | A CILO maps to |
| --- | --- |
| **Program-specific** | Your program's **Graduate Outcome (GO)** |
| **General Education** | An **Institutional Learning Outcome (ILO)** |

:::caution
A Program-specific CILO has no Institutional outcomes available, and a General
Education CILO has no Graduate Outcomes available. If the list looks wrong, the
Course's **Course Scope** is wrong — ask the Secretary to correct it.
:::

## Add or update an alignment

1. Open **Manage CILOs** for the Course, then open its **Course Alignment** workspace.
2. For each CILO, choose the outcome it maps to.
3. Choose the manifestation value.
4. Save.

The workspace shows every CILO in the Course at once, so you can spot the ones
still unmapped.

## Choose the manifestation value

| Value | Use it when |
| --- | --- |
| **Introduced** | The Course first exposes the outcome, with light coverage |
| **Reinforced** | The Course develops an outcome introduced earlier |
| **Assessed** | The Course evaluates the outcome directly |

One CILO may map to more than one outcome, and one outcome may be supported by
CILOs in many Courses. That many-to-many shape is normal and System CLOIE
discloses it when it reports a figure.

:::caution
One CILO can carry **many Likert questions**. If you need more statements, add
questions to the same CILO rather than creating a near-duplicate CILO.
:::

## Check readiness

The alignment workspace shows each CILO's state. A Course context is **ready**
when **every active CILO** has an outcome and a manifestation value.

## Why alignment matters before publication

:::caution
**Publication of a Course-bound evaluation is blocked until every active CILO
satisfies the typed alignment rule.** This is not a warning.

It exists because a submitted rating is only evidence about an outcome if you said
which outcome it was measuring. Publishing first would collect responses that
cannot be attributed to anything.

If you cannot publish, check this page first — see
[I cannot publish an evaluation](/troubleshooting/cannot-publish-evaluation/).
:::
