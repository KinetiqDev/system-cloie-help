**Published Evaluation** is your detail view for a running or finished Course
evaluation.

## Evaluation status

| Status | Meaning |
| --- | --- |
| Scheduled | Published; the activation time has not arrived |
| Active | Open to respondents now |
| Closed | The window has ended, or you closed it |

Only an **Active** evaluation accepts new submissions.

## Completion summary

The summary reports **Assigned**, **Responses**, and the completion percentage.

Completion measures participation, not satisfaction. A 30% completion with strong
ratings is not better evidence than a 70% completion — it is thinner evidence, and
you should say so when you use the numbers.

## Review submitted responses

Select a submitted response to open the answer detail.

:::caution
**You see anonymized responses.** The Program Head is the only role that sees
identified respondent detail. A response listing your own Students by name is not
something the application will show you, and it should not be reconstructed
from written comments either.
:::

In-progress drafts are never fetched and never displayed. You cannot tell who
has started but not finished.

## Written feedback

Respondents' written answers appear per response, alongside their ratings.

:::caution
Written comments are not cleared for unrestricted reuse. Removing a name does not
make a comment publishable. Treat any reuse of qualitative feedback as a separate
privacy decision.
:::

## After the window closes

- Close the evaluation so it stops appearing to Students.
- Read the outcome-level picture at [Faculty analytics](/faculty/analytics/).
- Submit your own view of the CILO results to your Program Head through your
  normal CQI process — System CLOIE collects evidence, it does not file the
  analysis for you.
