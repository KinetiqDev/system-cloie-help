An **evaluation tool** is the question set you publish a Course evaluation from.
You build one per Course, derived from a template the institution provides.

## Start from an available template

1. Open **Evaluation Tools**.
2. Select **New Tool**.
3. Choose to build **from** an available baseline template.
4. Name the tool after the Course and term — for example `BSIT 31 — Midterm
   CILO evaluation, A.Y. 2026–2027, First Semester`.
5. Review the inherited questions and edit what you need.

Deriving from a template rather than starting blank keeps your scale consistent
with every other course, which is what makes the evidence comparable.

## Create a derived Course-bound tool

The new tool is a **Course-bound** copy. Editing it does not change the
institutional template it came from, and no other Course sees your changes.

## Add questions

| Type | Use it for |
| --- | --- |
| **Likert** | A rating statement on the tool's scale |
| **Guided Open-Ended** | A written prompt with guidance |
| **Predefined Responses** | A fixed choice list |

Group questions into **sections**. Respondents see sections in order, and a
section with no questions is not shown.

:::caution
Keep it short. The evaluation is answered on a phone, inside an ordinary class
period. A long instrument collects worse answers, not more evidence.
:::

## Bind questions to CILOs

For each Likert question, choose which CILO it measures. Those bindings are how
a Student rating becomes GO evidence in your Program's analytics.

You can bind several questions to the same CILO — that is expected and correct.
What you cannot do is leave a rating question unbound and expect it to carry
outcome evidence.

## Save and edit

Saving keeps you in the editor. Every save is reversible **until publication**.

## Published versions stay fixed

:::caution
Publishing freezes the version your evaluation runs on. Later edits create a
**new version**; they never alter an evaluation that is already scheduled,
running, or closed.

If you fix a typo in question 4 after publishing, the running evaluation still
shows the original text. This is deliberate — respondents who saw one wording
must not have their answers reinterpreted as if they had seen another.
:::

**Delete Template** only removes a tool that was never published from. Anything
with responses behind it stays.
